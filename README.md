### Fintech ML, in production.

I build and ship ML systems for fintech: credit risk scoring, fraud detection, and KYC automation. Most of that has been at neobanks and market intelligence platforms, taken from prototype through regulated deployment.

On the side I work on LLM internals, mostly around what refusal is made of and how fine-tuning changes it.

**Selected work**

| Repo | What it is |
|---|---|
| **[escapement](https://github.com/ElSnacko/escapement)** | Safety testing harness for open-weights models. Measures whether a checkpoint exploits an escape affordance when handed shell, file and network tools inside a sandbox. Public register at [escapements.org](https://escapements.org). |
| **[activation-steering-asymmetry](https://github.com/ElSnacko/activation-steering-asymmetry)** | The refusal axis is layer-local and steering is asymmetric. Reproduces arXiv:2512.16602 with a verification report. |
| **[feature-bootstrapping-toolkit](https://github.com/ElSnacko/feature-bootstrapping-toolkit)** | How much data a feature needs before its signal stabilises. Built for thin-file and emerging-market credit populations. |
| **[Open-JEV-VLA](https://github.com/ElSnacko/Open-JEV-VLA)** | Calibrated option-token readout and gating for vision-language-action policies. |
